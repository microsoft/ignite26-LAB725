# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB725: Hands-on: Network monitoring and troubleshooting
### Session description

Join to gain practical experience with Azure network monitoring, troubleshooting, traffic analytics, and security insights. Through real-world scenarios such as Connectivity monitoring and Private Link traffic visibility, you'll learn which tools to use, when to use them, and how to interpret data effectively. By the end, you'll be equipped to improve network resilience, strengthen security, accelerate issue resolution, reduce operational overhead, and enhance application performance.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

Open the [`attendee instructions/`](instructions/README.md) and follow the facilitator's guidance.

#### On your own

Follow the [`attendee instructions/`](instructions/README.md). The core lab runs in a browser; no local SDK or CLI setup is required.

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- See your network inventory and resource health. 
- Turn on monitoring on your entire network in 3 clicks.
- Troubleshoot connectivity issues like SNAT port exhaustion and custom UDR blocking traffic flow.
- Understand monitoring of traffic flowing through Private Link Service.
- Generate least-privilege NSG rules from real traffic flow.

### 💻 Technologies used

- Azure Network Watcher
- Connection monitor, with hop-by-hop topology and failure diagnosis
- Virtual network flow logs and Traffic analytics
- Azure Firewall, with SNAT port exhaustion
- Azure Private Link private
- Virtual network peering and user-defined routes
- Azure Monitor Log Analytics and Azure Workbooks
